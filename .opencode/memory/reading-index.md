# Reading Index

Use this file to map public-guide topics to source books. This mapping belongs to
`website/`. Consult the Substack catalog linked below
for matching published reviews. Keep a book's own source or store URL distinct
from its review URL when recording book metadata.

## Architecture Fundamentals, Qualities, And Styles

- `Fundamentals of Software Architecture` - supports architecture fundamentals, characteristics, styles, risk, modeling overview, role pages, and career topics.
- `Software Architecture in Practice` - supports architecture characteristics, documentation, evaluation, governance, economic analysis, and requirements framing.
- `Software Architecture Patterns` - supports specific style pages such as layered monolith, microkernel, event-driven, microservices, and space-based architecture.
- `Head First Software Architecture` - supports component thinking and design-for-change explanations.
- `Software Architecture Metrics` - supports metrics, signals, and measurable architecture quality.
- `Software Architecture: The Hard Parts` - supports boundaries, coupling, contracts, data ownership, distributed workflows, and trade-off analysis.
- `Balancing Coupling in Software Design` - supports modularity, coupling, and boundary pages.

## Architecture Documentation And Modeling

- `Software Systems Architecture: Working with Stakeholders Using Viewpoints and Perspectives` - supports visualizing architecture, architecture descriptions, evaluation, and role pages.
- `The C4 Model for Visualising Software Architecture` - supports the C4 model pages.

## Domain-Driven Design And Events

- `Learning Domain-Driven Design` - supports business domain, bounded context, domain modeling, and applying DDD in practice.
- `Patterns, Principles, and Practices of Domain-Driven Design` - supports DDD foundations, building blocks, integration, and best practices.
- `Introducing EventStorming` - supports discovery work and collaborative modeling.
- `Building Event-Driven Microservices`, `Designing Event-Driven Systems`, and `Enterprise Integration Patterns` - support event-driven architecture content.

## Data, Requirements, Communication, And Organization

- `Designing Data-Intensive Applications` - supports operational-data guidance.
- `Data Mesh` - supports analytical-data guidance.
- `Building Microservices` and `Microservice Architecture` - support microservices-based architecture pages.
- `Mastering the Requirements Process` - supports requirement definition, collection, scenarios, writing, testing, and communication.
- `Communication Patterns: A Guide for Developers and Architects` - supports visual, written, spoken, documentation, remote, and effective communication pages.
- `The Culture Map` - supports multi-cultural communication.
- `Team Topologies` - supports engineering organization.
- `Team of Teams` - supports alignment and organizational adaptability.
- `The Culture Code` - supports company and organizational culture.
- `The Wisdom of Teams` and `Essential Kanban Condensed` - support team effectiveness.
- `The Lean Product Playbook` - supports product development.
- `Measure What Matters` - supports goals and OKRs.
- `The Personal MBA` - supports business fundamentals.
- `The Software Architect Elevator` - supports architect role classification.
